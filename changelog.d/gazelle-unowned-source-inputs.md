### Fixed

- Gazelle now retains compiler-observed TypeScript and JavaScript imports from directories without a TypeScript target, alongside the existing JSON inputs. Source-mode compiler owners, including explicit resolve owners, remain dependencies while their observed implementation imports are followed under the consumer's configuration. Ordinary import traversal stops at emitted compiler owners and generated outputs. A retained declaration also retains its same-stem JavaScript twin, and that module's runtime package scope, when the twin is exported to the consumer. Source exports and visibility stay unchanged. Repeated generation no longer reports retained direct sources as dropped.
